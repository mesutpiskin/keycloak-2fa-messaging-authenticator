# Contributing

Contributions are welcome: bug reports, feature requests, new messaging providers, translations, documentation, and pull requests. Please open an issue first for significant changes.

The full guide, including development setup, compatibility checks, local testing, and commit conventions, is in [CONTRIBUTING.md](https://github.com/mesutpiskin/keycloak-2fa-messaging-authenticator/blob/main/CONTRIBUTING.md).

## Before opening a PR

- run `mvn -B verify`
- keep changes focused
- update docs when configuration or behavior changes

## Extending with custom senders

Implement `com.mesutpiskin.keycloak.auth.messaging.service.MessageSender` in a separate JAR and register it under:

```
META-INF/services/com.mesutpiskin.keycloak.auth.messaging.service.MessageSender
```

## Reporting issues

- Bugs, feature requests, and questions: [open an issue](https://github.com/mesutpiskin/keycloak-2fa-messaging-authenticator/issues/new/choose) using one of the templates.
- Security vulnerabilities: do not open a public issue. Follow the [security policy](https://github.com/mesutpiskin/keycloak-2fa-messaging-authenticator/blob/main/SECURITY.md) to report them privately.
- Accessibility barriers: see the [accessibility statement](https://github.com/mesutpiskin/keycloak-2fa-messaging-authenticator/blob/main/ACCESSIBILITY.md) and use the **Accessibility Issue** template.
