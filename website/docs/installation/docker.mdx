# Docker Installation

Example Dockerfile pattern:

```dockerfile
FROM maven:3.9.11-eclipse-temurin-21 AS builder
WORKDIR /workspace
COPY . .
RUN mvn -B verify

FROM quay.io/keycloak/keycloak:26.2
COPY --from=builder /workspace/target/keycloak-2fa-messaging-authenticator-*.jar /opt/keycloak/providers/
RUN /opt/keycloak/bin/kc.sh build
```
