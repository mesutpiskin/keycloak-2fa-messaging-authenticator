# Introduction

`keycloak-2fa-messaging-authenticator` is a Keycloak SPI extension that adds one-time password delivery through messaging channels.

## What it supports

- SMS with **Twilio**, **AWS SNS**, and **Vonage**
- **Telegram** bot delivery
- **WhatsApp** API delivery
- **Signal** through `signal-cli-rest-api`
- Enrollment via a required action
- Conditional and always-on authenticator variants
